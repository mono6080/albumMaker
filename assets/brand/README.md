# 品牌素材

Office 模板匯入後，把原稿裡各自畫的 logo 換成統一素材時用的檔案。流程與人工複核步驟見
[import-office-template SKILL](../../.agents/skills/import-office-template/SKILL.md) 的步驟 4。

| 檔案 | 尺寸 | 用在哪 |
|------|------|--------|
| `derni_logo_white.png` | 1867×1354 | 深色／中間色背景。純白無陰影 |
| `derni_logo_white_shadow.png` | 2293×1780 | 淺色背景。白字在淺底上會糊掉，需要陰影撐出輪廓 |

## 怎麼選

**量背景，不要用猜的。** 在 logo 框的四角＋中心各取一點背景色，換算亮度
（`0.299R + 0.587G + 0.114B`）：任一點 ≥ 215 就用含陰影版。

只採樣中心點會誤判——背景本身是原稿設計的一部分，同一個 logo 範圍內可能上半是純色、
下半疊在一朵白雲上（2026-08 這批的 6階 海洋與陸地就是這樣）。

## 含陰影版是怎麼算出來的

`derni_logo_white_shadow.png` 是對純白版套 SKILL 步驟 4b 的 `make_shadow_logo()` 產生的，
參數是**依「最終顯示寬度 262px」反推**的：

```
scale   = 262 / 1867 = 0.14033      顯示大小 / 源檔大小
close_r = round(2 / scale)  = 14    先閉合細縫
blur_r  = 10 / scale        = 71.3  目標是畫布上 10px 的柔邊
pad     = int(blur_r * 3)   = 213   留白圈
```

**這個檔案只在「顯示寬度接近 262px」時是對的。** 模糊半徑是在源檔解析度上做的，縮放比例
一變，畫布上實際的柔邊寬度就跟著變——顯示得比 262 小很多時，柔邊會被 `LANCZOS` 壓成一條
清晰細線，看起來像描邊而不是陰影。差距大就照上面的公式重算一份，不要直接沿用。

套用時位置與尺寸要換算（畫布多了 `pad` 圈留白）：

```
visible_ratio = 1867 / 2293 = 0.814          可見內容占整張的比例
total_width   = 目標可見寬 / visible_ratio
total_height  = total_width * 1780 / 2293
x = 原 logo 框中心x - total_width / 2
y = 原 logo 框中心y - total_height / 2
```

## 尺寸不要沿用原稿的框

原稿的 logo 是**橫式手寫體**，這個統一素材是**圓標在上、粗體 Derni 在下的直式**——同樣
寬度會高出一大截並蓋掉旁邊的元素。2026-08 這批實測，可見寬度取 **150px**（794 畫布）
與頁面比例協調；正式站 202607 那批是 126px。換完一定要算圖看過再定案。
