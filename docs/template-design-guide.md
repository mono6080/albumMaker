# 設計組模板製作使用教學

正式交付設計組請使用帶截圖標示的 PDF 版本：`docs/template-design-guide-step-by-step-dom.pdf`。

這份文件給負責版型與美術素材的設計人員使用。目標是做出老師可以直接套用的相本模板：每頁背景完整、照片格數量正確、文字位置可讀，最後輸出的 PDF 與模板編輯器看到的畫面一致。

## 1. 開始前準備

請先準備：

- 每頁背景圖：建議 A4 直式比例，解析度至少 `794 x 1123`，避免重要文字或圖案貼齊邊界。
- 貼圖素材：建議 PNG 透明背景。
- 每頁預計照片數量：先決定每頁要放幾張照片，方便用「照片總計」檢查。
- 可替換文字內容：例如 `{name} 的感官探索`；`{name}` 代入相本稱呼，
  `{full_name}` 代入名冊完整姓名。

登入後進入「模板管理」，建立或編輯模板。

## 2. 建立模板與頁面

1. 在「模板管理」輸入模板名稱，格式固定為 `YYYY-MM {年級} {主題名稱}`，例如 `2026-05 中班 感官世界`。
2. 點「建立」。
3. 進入模板後，如果沒有頁面，點「新增第一頁」。
4. 左側「頁面」區可切換頁面，也可點「新增頁」增加新頁。
5. 每次完成一段編輯後，點右上角「儲存」。

模板命名規範：`YYYY-MM {年級} {主題名稱}`，例如 `2026-06 大班 端午探索`。

## 3. 上傳背景

1. 左側「素材」點「上傳背景」。
2. 選擇背景圖。
3. 在裁切視窗中調整位置與縮放，讓背景完整覆蓋 A4 畫布。
4. 確認後背景會套用到目前頁面。

注意事項：

- 每一頁都要分別上傳自己的背景。
- 背景不要包含需要老師後續修改的學生姓名；相本稱呼請用文字元素 `{name}`，
  必須顯示完整姓名時用 `{full_name}`。
- 背景上的裝飾不要壓到照片格或主要文字區。

## 4. 放置照片格

1. 左側工具選「照片格」。
2. 在畫布上點一下新增照片格。
3. 目前工具會保持在照片格模式，可以連續點擊新增多個照片格。
4. 拖曳照片格可移動位置。
5. 拖曳四角可調整大小，頂部圓點可旋轉。
6. 右側屬性面板可調整尺寸、圓角、外框與陰影。

右上角會顯示「照片總計 X 張」，這是整個模板所有頁面的照片格總數。完成模板前請用這個數字確認和企劃需求一致。

照片格建議：

- 同一頁照片格大小盡量一致，除非版面刻意做主次照片。
- 避免照片格太小，老師上傳照片後臉部容易看不清。
- 需要直式/橫式快速互換時，可在右側「位置與尺寸」點「翻轉長寬」。
- 如果照片格有旋轉，角度建議控制在 `-8` 到 `8` 度，避免照片被裁太多。

## 5. 加文字

模板文字使用「純文字」工具，適合標題、日期、短句與對應文字。

操作方式：

1. 左側選「純文字」。
2. 在畫布上點擊新增文字。
3. 右側可修改文字內容、字體、字級、顏色、對齊、行距。
4. 要顯示相本稱呼時插入 `{name}`；要顯示名冊完整姓名時插入 `{full_name}`。
5. 也可以手動輸入變數，例如 `今天的主角是 {name}`。
6. 需要突出文字時，可開啟「文字陰影」，調整陰影顏色、偏移、模糊與不透明度。

文字建議：

- 正文不要太小，建議 `20pt` 以上。
- 深色背景用淺色字，淺色背景用深色字。
- 文字陰影適合用在背景較花的區域，但不要模糊過重。
- 不要把重要文字放到裁切邊緣。

## 6. 上傳與使用貼圖

1. 左側「素材」點「貼圖素材」。
2. 選擇 PNG 或圖片檔。
3. 上傳後會出現在目前頁面，可拖曳、縮放、旋轉。
4. 右側屬性面板可調整位置、尺寸與層次。

貼圖建議：

- 優先使用透明 PNG。
- 避免貼圖壓住學生臉部或主要文字。
- 如果貼圖只是裝飾，層次可放在照片格下方；如果是章標或標籤，可放在上方。

### 群組任何畫布物件

1. 按住 `Shift` 點選，或在畫布空白處拖拉多選框；照片格、純文字、貼圖與既有群組都可混合
   選取，不需要位於相鄰圖層。
2. 選「建立群組」或按 `Ctrl/Cmd + G`。新群組會放在所選物件中最上層物件的位置，其他未選圖層的
   相對順序不變。
3. 群組可以包含群組。雙擊群組或按 Enter 一次進入一層；按 `Esc`、點「離開群組」，或雙擊目前群組
   外面一次退出一層。
4. 在群組外拖曳、旋轉或從四角縮放會操作整個 subtree；文字框會改變外框，但字級、字距與行高不會
   跟著群組縮放。進入群組後，各物件仍可依原本規則獨立調整。
5. 只選一個完整群組再按 `Ctrl/Cmd + G` 可解除該層群組，不會遞迴拆散內部群組。方向鍵移動 1 px，
   `Shift + 方向鍵` 移動 10 px。

貼圖含有適合放文字的框面時，可選「分析圖片並建立文字框」快速新增普通文字框；也可同時選取貼圖
與既有文字後選「符合素材並連結文字框」。已連結後，「重新分析並重設文字框」只重設文字框的位置、
尺寸與角度。這是與群組分開的一次性排版捷徑：不會自動群組、不會建立安全區，也不會因文字放不下
而拉伸貼圖、改字級或改內容；文字是否完整仍需在預覽中人工確認。

## 7. 層次與選取

選取任一元素後，右側「層次」可調整：

- 最底
- 下移
- 上移
- 最頂

常見層次順序：

1. 背景圖
2. 裝飾貼圖
3. 照片格
4. 文字與標籤
5. 需要蓋在最上面的貼圖

如果點不到某個元素，通常是被上層元素擋住；可先選上層元素並下移，或暫時移開。

## 8. 復原、重做與儲存

模板編輯器支援：

- 復原：`Ctrl + Z`
- 重做：`Ctrl + Y` 或 `Ctrl + Shift + Z`
- 右上角也有復原/重做按鈕

注意：

- 復原/重做以目前頁面為單位。
- 切換頁面前建議先儲存。
- 使用雙頁預覽前，系統會先儲存目前草稿，確保看到最新版本。

## 9. 雙頁預覽

右上角點「雙頁預覽」可以查看兩頁合併的橫向效果。

用途：

- 檢查跨頁節奏是否順。
- 檢查左右頁照片量是否平衡。
- 檢查兩頁主色、字級、留白是否一致。
- 最後一頁若沒有下一頁，右側會以空白頁補齊。

建議每完成 2 頁就看一次雙頁預覽，避免整本做完才發現節奏不一致。

## 10. 交付前檢查表

交付模板前請逐項確認：

- 模板名稱正確，格式為 `YYYY-MM {年級} {主題名稱}`。
- 每頁背景都已上傳。
- 照片總計符合需求。
- 每個照片格尺寸、位置、旋轉角度合理。
- 純文字沒有超出框線。
- 顯示相本稱呼的地方使用 `{name}`；確實需要完整姓名的地方使用 `{full_name}`。
- 文字顏色與背景對比足夠。
- 文字陰影不會太重或太模糊。
- 貼圖沒有遮住照片格主要區域。
- 層次正確，文字不會被照片或貼圖蓋住。
- 已用雙頁預覽檢查每組左右頁。
- 最後已按「儲存」。

## 11. 常見問題

### 照片總計不對

逐頁檢查是否有多放或少放照片格。刪除多餘照片格後記得儲存。

### 背景看起來被裁掉

重新上傳背景，在裁切視窗調整位置與縮放。背景原圖若不是 A4 比例，一定會有局部裁切。

### 文字在背景上不清楚

調整文字顏色、位置或字級，必要時開啟文字陰影。

### 照片格方向放反

選取照片格，在右側「位置與尺寸」點「翻轉長寬」。

### 預覽看起來不是最新

先按「儲存」，再重新開啟雙頁預覽。
