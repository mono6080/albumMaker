# 老師製作相冊使用教學

正式交付老師請使用帶截圖標示的 PDF 版本：`docs/teacher-album-guide-step-by-step.pdf`。

這份文件給帶班老師使用。目標是完成每位學生的相冊：建立相本專案、登記學生、填整班共用文字、逐位上傳照片、確認預覽，最後下載 PDF 或全部 ZIP。

## 1. 建立相本專案

1. 登入後進入「相本專案」。
2. 點「新建專案」。
3. 選擇本月要使用的模板。
4. 輸入班級或月份補充名稱。
5. 確認專案全名後點「建立」。

## 2. 登記學生

1. 進入專案卡片的「專案設定」。
2. 在「新增學生名單」貼上姓名。
3. 可以一行一位，也可以用逗號或頓號分隔。
4. 點「新增」。
5. 在已登記學生清單確認人數與姓名。

## 3. 填整班共用文字

1. 在專案設定切到「文字」。
2. 用頁面切換逐頁檢查文字欄位。
3. 填入全班共用文案。
4. 需要學生姓名時點「插入 `{name}`」，輸出時會自動替換。
5. 若欄位清空，系統會自動恢復模板文字。
6. 右側預覽確認文字位置與內容。

## 4. 逐位編輯學生

1. 從專案進入「個人編輯」。
2. 點學生卡片的「編輯」。
3. 在照片管理中上傳照片。
4. 可用「多選上傳」一次放入多張照片。
5. 需要只改這位學生的文字時，在個別文字欄位覆寫。
6. 需要學生姓名時點「插入 `{name}`」。
7. 若個別文字欄位清空，系統會自動恢復專案共用文字或模板文字。
8. 左側預覽確認照片與文字。

## 5. 輸出 PDF

1. 每位學生完成後點「產出並下載」。
2. 回到個人編輯總覽確認進度。
3. 全部完成後點「下載全部 ZIP」。
4. 若主管或設計有留言，請在「審閱意見」確認。

## 交付前檢查

- 專案使用正確模板。
- 學生名單完整且沒有重複。
- 整班共用文字已填好。
- 每位學生照片格都已補齊。
- 個別文字沒有漏填或超出畫面。
- 不需要的頁面已刪除。
- 每位學生 PDF 已產生。
- 全部 ZIP 可正常開啟。
