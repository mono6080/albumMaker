# 老師製作相本使用教學

正式交付老師請使用帶截圖標示的 PDF 版本：`docs/teacher-album-guide-step-by-step.pdf`。

這份文件給帶班老師使用。整個流程是：從目前任教班級進入相本 → 主教建立新一期 → 系統帶入園所設定的學生名單與老師權限 → 編輯全班共用內容 → 逐位微調 → 標記全班完成 → 下載交件。

## 1. 從目前班級建立新一期相本

1. 登入後進入「相本工作」，畫面會依園所設定列出你目前任教的班級。
2. 每個班級下直接列出各期相本；不會再有一份與班級分離的專案清單。
3. 主教點班級右上「建立新一期相本」，選該班部門可用的期別與模板，再填相本名稱。
4. 系統會以班級目前學生建立本期固定快照；所有目前當班老師都可製作，主教是進度負責人。
5. 協同老師不能建立新一期，但主教建立後會直接在同一班級下看到並可編輯。

如果看不到班級、職責或學生不正確，請先請管理員在「園所設定」修正；不要另外建立未歸班相本。
主管可查看哪些老師進度，也由管理員在「園所設定」安排的分校／部門主管範圍決定，不需逐位老師另外指定主管。

## 2. 相本卡片與班級總覽

每張相本卡片下方有兩個入口：

- **編輯相本**：放照片、填文字都從這裡進去。
- **班級總覽**：看進度、核對這一期的學生快照、標記完成與下載交件。

「班級總覽」最上方的橫幅一條看完三件事：

1. 目前階段：1 製作 → 2 全班完成 → 3 交件。
2. 全班照片進度；點「缺照片 N 位」會直接篩選出還缺照片的學生。
3. 依階段建議的下一步按鈕（製作中是「繼續製作」）。

下方是學生卡片：點名字或鉛筆進個別編輯，點頁面縮圖直接放大預覽。

## 3. 核對這一期的學生快照

1. 新一期建立時已帶入園所設定中的目前學生，不需每一期重新貼一次名單。
2. 在班級總覽點「本期學生」，核對這一本相本的固定快照。
3. 完整姓名是名冊與檔案辨識依據，在相本內只讀；老師不需也不能在每一期另外新增、改名或刪除學生。
4. 相本只想顯示名字或暱稱時，可編輯「相本稱呼」；留空就沿用完整姓名。
5. 若是班級目前名單本身錯誤，請管理員回園所設定修正；該修正只影響之後建立的相本，不會偷偷改寫既有相本。

## 4. 編輯全班共用內容（照片與文字）

從相本卡片的「編輯相本」或班級總覽的「繼續製作」進入，預設是「全班」範圍：這裡做的事會套用到所有學生。畫面三欄：頁面預覽｜照片管理｜頁面文字，和個別編輯是同一套版面，右上可隨時切回「班級總覽」。

1. 用頁碼導航切頁，三個面板會一起換頁。
2. 點一個照片格，會開「放照片」視窗選分配方式：
   - **每人不同張**：一次上傳多張，自動分給每位學生（最常用）。
   - **全班同一張**：團體照等共用照片，一張套用到全班同一格。
3. 行政已照「姓名＋頁格」命名好的整批檔案，用照片面板右上的「依檔名整批匯入」。
4. 在全班文字填共用文案；`{name}` 會代入相本稱呼（未設定時沿用完整姓名），
   `{full_name}` 則固定代入完整姓名。
5. 清空欄位會輸出空白；按「恢復預設」可回到模板文字。

## 5. 個別學生微調

在編輯相本用編輯範圍切換按「個別」，或從班級總覽點某位學生進入。

1. 用「上一位／下一位」或下拉一位一位輪著做，不用回列表；按「全班」可切回全班共用內容。
2. 照片管理點空格上傳；已有照片可調整裁切、更換、刪除或拖曳交換。
3. 照片管理右上可切「本頁／整本」：整本檢視能一次上傳整本照片、跨頁調換。
4. 「多選上傳」一次選多張，自動填入剩餘空格。
5. 只想改這位學生的文字時，在個別文字覆寫；按恢復預設可回到全班文字。
6. 這位學生不需要某一頁時，在預覽區頁尾點「刪除此頁」，之後也能還原。
7. 做完按右上角的「班級總覽」回工作台。下載都在班級總覽，個別編輯頁沒有下載按鈕。

## 6. 全班完成與交件下載

1. 全班照片備齊後，班級總覽橫幅會自動跳到階段 2。
2. 逐位點學生卡片縮圖預覽，確認照片、相本稱呼與姓名文字都正確。
3. 按「全班完成」。標記後內容鎖定，需主管或管理員按「退回修改」才能再修改。
4. 用「PDF ZIP」批次下載全班 PDF；「全部圖片」下載每頁圖片（手機會開啟系統分享）。
5. 也可以在學生卡片上只下載單一學生的 PDF 或圖片。
6. 主管或設計組留了審閱意見時，會顯示在班級總覽下方的「審閱意見」。

## 交付前檢查

- 相本位於正確的分校／班級，並使用正確期別與模板。
- 園所設定的帶班老師與目前學生正確；本期學生快照完整且沒有重複。
- 每位學生的相本稱呼已確認；需要全名的版位使用 `{full_name}`。
- 全班共用照片與文字已填好。
- 每位學生照片格都已補齊（橫幅顯示「全班照片齊」）。
- 個別文字沒有漏填或超出畫面。
- 不需要的頁面已刪除。
- 每位學生的每一頁都已預覽。
- 已按「全班完成」標記。
- PDF ZIP 下載後可正常開啟。
- 審閱意見已確認。
